## ЛР 2. Страницы приложения и навигация

### Результат

Приложение Task Tracker из ЛР 1 превращено в многостраничное SPA на React Router (декларативный режим).
Вместо пустого раздела появились список задач, страница подробностей, страница создания с заглушкой и страница неизвестного адреса. 
Все экраны используют общий layout с навигацией. Данные хранятся в типизированном массиве, HTTP и Supabase пока не подключены.
Записи демонстрационные.

### Маршруты

| Адрес | Что показывает |
|-------|----------------|
| `/` | Перенаправление на `/tasks` |
| `/tasks` | Список задач (5 записей) |
| `/tasks/:id` | Подробности задачи, например `/tasks/t1` |
| `/tasks/new` | Заглушка создания: форма появится в ЛР 3 |
| `/tasks/missing` (любой id, которого нет) | Сообщение «Задача не найдена» |
| любой другой адрес, например `/unknown` | Страница «Страница не найдена» |

### Что добавлено

- Зависимость `react-router` (версия зафиксирована в `package-lock.json`).
- `src/types/task.ts`: типы `Task`, `TaskStatus`, `TaskPriority`.
- `src/data/tasks.ts`: 5 демонстрационных задач с разными статусами и приоритетами.
- `src/components/TaskCard.tsx`: карточка задачи с типизированными props, русские подписи статуса и приоритета.
- `src/pages/TasksPage.tsx`: список через `map` с `key={task.id}`, сообщение при пустом списке.
- `src/pages/TaskDetailsPage.tsx`: поиск задачи по `useParams`, все поля, сообщение об отсутствующей записи.
- `src/pages/NewTaskPage.tsx`: заглушка создания со ссылкой на список.
- `src/pages/NotFoundPage.tsx`: неизвестный адрес со ссылкой на список.
- `src/app/AppLayout.tsx`: общая шапка, `NavLink` и `Outlet`.
- `src/main.tsx`: единственный `BrowserRouter`.
- `src/App.tsx`: схема маршрутов.
- `src/App.css`: стили навигации, активной ссылки, фокуса и адаптивной сетки карточек.

### Как проверить

1. В каталоге `frontend` выполнить `npm ci` и `npm run dev`.
2. Открыть `/`: происходит переход на `/tasks`, виден список из пяти карточек.
3. Открыть две разные карточки и сравнить содержимое.
4. Скопировать адрес карточки, открыть в новой вкладке и обновить страницу: карточка открывается.
5. Нажать «Добавить задачу» или «Создать»: видны заглушка и общая навигация.
6. Открыть `/unknown`: видна страница «Страница не найдена».
7. Открыть `/tasks/missing`: видно сообщение «Задача не найдена».
8. Временно заменить массив задач на пустой: виден текст «Задач пока нет.» Затем вернуть пять записей.
9. Проверить кнопки «назад» и «вперёд», ширину около 360 px (нет горизонтальной прокрутки) и переходы клавишей Tab с видимым фокусом.
10. В Network очистить список и перейти между страницами: при клике по внутренним ссылкам HTML-документ заново не загружается.
11. Выполнить `npm run build` и `npm run preview`, повторить прямое открытие карточки. В консоли нет ошибок и предупреждений о `key`.

### Примечания

- Прямое открытие адресов вроде `/tasks/t1` работает в `npm run dev` и `npm run preview`. Для публичного хостинга понадобится возврат `index.html` для SPA, это будет настроено в ЛР 10.
- Создание, редактирование и удаление записей через формы появятся в ЛР 3.
